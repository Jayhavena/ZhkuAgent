# 本机模型工具调用演示

在 **`D:\alldesk\Projects\ZhkuAgent-lineB`** 的 PowerShell 中执行。此入口只演示模型选择课程学分汇总工具，不连接教务系统，也不能判断课程或毕业资格。依赖版本为 Spring AI 1.0.9；端点、模型名和密钥环境变量名来自现有本机预览 profile，密钥值不入命令、配置或日志。

先运行离线契约（Maven 使用本地缓存；协议测试只访问本机 `127.0.0.1` 假供应商，无需外网、数据库或模型密钥）：

```powershell
$repo = Join-Path $env:USERPROFILE '.m2\repository'
.\mvnw.cmd -o -pl knowledge "-Dmaven.repo.local=$repo" '-Dtest=CourseCreditSpringAiProtocolContractTest,CourseCreditModelCallServiceTest,CourseCreditSummaryToolTest,CampusToolRegistryTest,SpringAiAdapterContractTest' test
```

默认入口不会连接供应商：

```powershell
.\mvnw.cmd -o -pl knowledge "-Dmaven.repo.local=$repo" '-Dexec.mainClass=com.zhku.knowledge.tools.modelcall.CourseCreditModelCallCli' compile exec:java
```

只有已在当前进程设置现有 profile 指定的 `DASHSCOPE_API_KEY`、且明确传 `--live`，才做真实供应商冒烟。输入一行自然语言问题，**同时写出各课程的标识、类别和学分**，例如“请汇总 MA101（必修，3 学分）和 GE002（通识，1.5 学分）总共多少学分”。模型是否请求工具由供应商响应决定；无请求时受控返回 `NO_TOOL_CALL`。

```powershell
$question = Read-Host '课程学分问题'
$question | .\mvnw.cmd -pl knowledge "-Dmaven.repo.local=$repo" '-Dexec.mainClass=com.zhku.knowledge.tools.modelcall.CourseCreditModelCallCli' '-Dexec.args=--live' compile exec:java
```

成功时应出现 `tool=summarize_course_credits`、`status=SUCCESS`、`result`（含 `totalCredits`）及原工具的边界提示。缺密钥为 `CONFIG_UNAVAILABLE`；超时、供应商失败、模型不调用工具或不合规参数均不会输出猜测的学分。只有实际看到上述成功输出，才可将本机这次运行记为“真实模型工具调用已验证”；离线测试通过本身不构成该证据。

当前验证口径：**本机供应商协议合同已验证；真实 DashScope tool-call 仍因缺少 DASHSCOPE_API_KEY 未验证**。协议测试使用与 CLI 相同的模型构建路径，检查唯一工具及完整 schema 已送到本机端点、标准 `tool_calls` 可被 Spring AI 解析并由注册表执行，以及普通文本、未知工具、非法参数和供应商错误不会产生伪造学分。测试不打印请求问题或鉴权值。
