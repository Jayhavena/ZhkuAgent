## 项目目标和模块

主目标是校园教务规则查证：理解问题及补充条件，在权限和预算内检索/读取已审核证据，形成有出处的解释、必要追问或明确缺口。当前仍限受控本机用途与2025.9.2历史本科资料，不推断现行政策或个人资格，不办理教务事务。

用户确认的最终业务目标是**答案及依据质量不下降，查证耗时降低**。尚无真实学生与直接查PDF的对照结果，不能宣布该目标达成。

| 模块 | 已有职责与边界 |
| --- | --- |
| agent-runtime | 共享Run、工具调用、事件、停止与资源生命周期，不处理校园政策 |
| knowledge | 资料治理、审核发布、证据检索/核验、校园学分实验及独立规则Agent循环 |
| agent | 保留通用Agent实验，不是本次规则业务宿主 |
| agent/frontend | 学生、工程、replay三种配套构建；回放与异步任务不能混配 |
| 外部资产 | 审核资料/PDF、本机依赖及凭证；不随Git单独恢复，也不进入公开上传范围 |

当前规则链路是中文二元组词法检索、资格过滤、证据读取和审计。仓库保留向量/混合检索实现，不表示本链路使用它们或已证明收益。
