## 1. 项目定位与范围

主目标是面向学生的校园教务规则查证：根据问题和补充条件，在资料、权限及执行预算内检索和读取证据，形成有依据的解释、必要澄清或明确缺口。首期沿用已审核的 2025.9.2 历史资料及受控本机用途，不承诺现行政策适用、个人资格认定或教务办理。

最终业务目标仍是用户已确认的两项：**答案及依据质量不下降，查证耗时降低**。必须通过真实学生与直接查 PDF 的对照观察判断，目前没有该项结果。

| 部分 | 当前职责与边界 |
| --- | --- |
| `agent-runtime/` | 两个应用共用的 Run、工具调用、事件、停止与资源生命周期；不处理校园政策 |
| `knowledge/` | 资料治理、审核发布、证据检索/核验、校园学分实验及新的规则查证 Agent 主循环 |
| `agent/` | 保留通用 Agent 工程实验；不是规则查证业务宿主 |
| `agent/frontend/` | Vue 前端；学生、工程实验、离线回放通过不同构建入口选择配套合同 |
| 外部资产 | 已审核资料、原 PDF、数据库、凭证和本机依赖；Git 提交不能单独恢复这些资产 |

当前规则任务链路实际使用中文二元组词法检索、资格过滤和证据读取/审计。仓库虽保留向量与混合检索实现，不能据此声称当前规则 Agent 已使用向量检索、重排，或已取得相应收益。源码入口见 [ReviewedToolsConfiguration](../../knowledge/src/main/java/com/zhku/knowledge/ruleagent/web/RuleAgentReviewedToolsConfiguration.java)。
