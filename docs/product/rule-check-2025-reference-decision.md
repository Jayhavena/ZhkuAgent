# 首轮资料版本决定：2025版

日期：2026-10-08。决定来源：用户明确指示“先以2025版为准”。

- 首轮开发、条款核对和评估固定使用已记录的2025版手册快照。2026版正文取得不再作为这一限定范围试验的前置条件。
- 回答和评估明确写“依据2025版手册”，只判断指定文本支持什么。用户询问当前学年或新版本是否仍有效时，说明尚未核实的范围，不能从选择2025版推导出现行适用。
- 原件记录：本机2025.9.2版本，SHA-256 `dd036279ca21beea40351815d21d6d49f1037448a4df45c95e1eb2f8b199f653`；相关页的物理页与印刷页分开。来源观察及原文件核对见[R0来源核验](../evidence/rule-check-refactor/2026-10-07/r0-baseline-01/source-audit.md)。该记录不补造在线附件字节核验。
- 这次决定确认的是使用版本，不代表人工参考已经审核、资料已学生可见或分享资格已经改为true。不修改外部原件、原库或旧审核标记。
- B-01剩余任务缩小为2025版本主题的来源/原文位置、范围、相关条件与例外、展示资格核对；B-02仍需人工参考。G0不能仅因版本选择自动通过。

人工参考是：人对照原文确认一题应如何处理，包括预期状态、必要事实、条件/例外、证据位置、未知项和禁说结论。语义相同的不同表达可以合格；不要求每题只有一段固定答案。

Codex可整理条款和参考草稿、指出歧义并执行测试。开发者可以亲自核对，记录核对人、日期和理由；仅选择版本不能把AI草稿改标为人工已审。人工核对不等于教务部门背书。
