# 首页（外壳）重设计方案

> 状态：**已实施**（2026-09-17，提交 `de6fc65`）。实施范围：Home.vue 重写 +
> AppFooter 令牌化 + style.css 令牌增补；验收截图见 `assets/home.visual-check.*.png`。
> 对话页卡片结构不在本次范围，仍等阶段 8 回答卡契约冻结。

## 1. 现状问题

| 问题 | 说明 |
| --- | --- |
| 风格错配 | 赛博朋克霓虹 glitch 风，与"可信校园问答助手"的产品气质相反 |
| 风格断裂 | 首页深蓝霓虹、对话页朴素白底，像两个产品 |
| 只有暗色 | 硬编码 `--cyber-dark` 背景，不跟随系统明暗 |
| 动效过度 | 标题 glitch 抖动 + 背景三光圈漂浮，干扰注意力且无信息价值 |
| 外部依赖 | 从 Google Fonts 加载 Orbitron，本机演示离线时字体回退难看 |

## 2. 设计方向

**关键词：校园、可信、安静。** 参照 Claude/ChatGPT 的着陆页思路——
一个清晰的标题、一句话说明、一个明确的入口，仅此而已。

- 主色：绿色系（呼应仲恺校绿，具体色值实施前核对校徽标准色；
  暂定主绿 `#0f6e56` 一档，浅色模式更深、暗色模式更亮）；
- 明暗：跟随系统，两套令牌在 `style.css` 已预留翻转结构；
- 字体：系统中文字体栈（沿用 `App.vue` 的 PingFang/雅黑栈），
  去掉 Google Fonts 外部依赖；
- 动效：只保留一处克制的微交互（卡片 hover 上浮 + 阴影加深），
  删除 glitch 与漂浮光圈。

## 3. 信息架构与布局

保持不变的信息：产品名「仲园 Agent」、一句话定位、唯一入口卡片
「任务助手」、页脚。单入口是产品现状，不为了填满版面虚构第二张卡。

```
┌─────────────────────────────────────┐
│                                     │
│           仲园 Agent                │  ← 标题，字重 500，非霓虹
│      校园可信问答 · 本机演示         │  ← 副标题，辅助色小字
│                                     │
│   ┌───────────────────────────┐     │
│   │  任务助手              →  │     │  ← 唯一入口卡，整卡可点
│   │  提交任务，查看过程与结果  │     │
│   └───────────────────────────┘     │
│                                     │
│              页脚                   │
└─────────────────────────────────────┘
```

- 内容整体居中，最大行宽 `--space-chat-max-width`（768px）；
- 卡片左文右箭头，取代现在的"图标居上 + 按钮居下"——减少一层视觉噪音；
- 机器人 emoji 图标替换为简单几何图形或字母标（避免 emoji 渲染差异），
  或复用现有 `AiAvatarFallback.vue` 的思路。

## 4. 令牌增补清单（写入 style.css，组件只引用变量）

| 变量 | 用途 |
| --- | --- |
| `--color-brand` | 品牌主绿（标题强调、卡片边框 hover、箭头） |
| `--color-page-bg` / `--color-surface` | 页面底 / 卡片底（明暗各一值） |
| `--color-text-primary` / `--color-text-secondary` | 标题 / 副标题与描述 |
| `--shadow-card` / `--shadow-card-hover` | 卡片常态 / hover 阴影 |
| `--duration-hover` | hover 过渡时长（约 200ms，统一节奏） |

## 5. 移动端铺垫纪律（只铺垫，不适配）

- 宽度一律 `max-width` + `flex`/百分比，禁止写死固定像素；
- 不断言设备断点、不写 `@media` 分支、不做手机尺寸截图验收；
- 现状 `App.vue`/`Home.vue` 已有基础断点，重设计时保留不删即可。

## 6. 明确不做（沿用已拍板决策）

登录、多会话侧边栏、模型切换器；本次另加：不加第二张占位应用卡、
不引入 UI 框架/组件库（单页用原生 CSS 足够，引入依赖反而增加维护面）。

## 7. 实施步骤（动手时按此走）

1. 在 SYNC-STATUS 登记前端改动归属；
2. `style.css` 增补第 4 节令牌（含暗色翻转）；
3. 重写 `Home.vue` 的 template + scoped style（删除赛博朋克全部样式与
   Google Fonts 引入）；
4. 视觉验收：1440×900 明/暗两张截图，走程序化检查（对比度、溢出、
   无横向滚动）+ 与参照库做审美对比（比例/层级/配色优先于像素对齐）；
5. 证据截图按 `docs/zhkuagent` 的 visual-check 惯例存档；
6. 按 stage 纪律只提交 `agent/frontend/` 与本文档。

## 8. 验收标准

- 明/暗两主题下对比度均可读，无硬编码色值漏网；
- 页面无闪烁动画，首屏注意力落在标题与入口卡；
- 1280px～1920px 宽度下布局居中不破版（移动端不测但桌面窄窗不崩）；
- 无任何外部网络字体依赖。
