# 参照：ChatGPT / Claude —— 对话基础体验

## 解决什么问题

长对话中用户需要快速区分「谁在说」并舒适地阅读大段文本；
流式输出时需要明确的「正在生成」状态，避免界面看起来卡死。

## 抄什么

- **气泡层级**：用户消息与 AI 消息用对齐方式和底色区分
  （用户靠右着色、AI 靠左弱底色或无边框），而非都套相同样式；
- **留白节奏**：消息间距大于段落间距，视觉分组先于文字阅读；
- **窄列阅读**：对话区限制最大行宽（约 700–768px），长文不拉满屏幕；
- **流式反馈**：生成中有光标/呼吸指示，完成后再渲染操作按钮
  （复制、反馈），避免按钮在流式期间抖动。

## 不抄什么

- 侧边栏多会话管理——当前产品边界是单会话演示，阶段 7–10 无此需求；
- 模型切换器、设置面板等完整产品外壳。

## 对令牌的启发

已对应 `style.css` 中的 `--color-bubble-*`、`--space-message-gap`、
`--space-chat-max-width`。流式光标若做动画，可后续增补
`--duration-streaming-cursor`。
