# 参照：Perplexity —— 引用与来源表达（阶段 8 核心参照）

## 解决什么问题

AI 回答需要「可信」：用户要能一眼看到每个结论出自哪条证据，
并能核对原文。这正是阶段 8「仅用获准证据、引用可校验」的 UI 表达。

## 抄什么

- **行内引用编号**：结论句末尾挂上标式编号 `[1]`，点击定位到来源；
- **来源卡列表**：回答末尾集中列出来源（标题 + 出处 + 日期），
  一张卡对应一条证据，视觉上弱于正文、但可展开核对；
- **无证据时的表达**：回答缺来源时明确标注，而不是假装有底气——
  对应我们「缺元数据必须拒答/安全降级」的门禁，降级提示用
  `--color-degraded-warning` 而非错误红。

## 不抄什么

- 搜索框为首屏主角的布局——我们是校园问答助手，入口形态不同；
- 联网搜索过程的实时展示（我们的检索范围是受控校园资料，
  不暴露检索过程细节）。

## 对令牌的启发

已对应 `--color-citation-accent`（引用强调色，绿色系表「可信」）。
动手做引用卡时可能需要增补 `--radius-card` 之外的
`--space-citation-gap`（来源卡之间的紧凑间距）。
