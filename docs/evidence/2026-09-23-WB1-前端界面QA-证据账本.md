## 一、两张真机 8124 截图字节相同的 QA 结论（PM 派发第 1 项，已闭环）

**现象**：`local-admin.real-8124.1440x900.light.png` 与 `local-admin.real-8124.1440x900.dark.png`
字节数完全相同（243524 B）。

**证据（2026-09-23 复核）**：

| 项 | 值 |
| --- | --- |
| light 截图 | 243524 B，SHA256 `F0B7D364B907F819F7209A2C8D659AD3022F0442C7536823AF0FB4654BA7E07D` |
| dark 截图 | 243524 B，SHA256 `F0B7D364B907F819F7209A2C8D659AD3022F0442C7536823AF0FB4654BA7E07D` |
| `local-admin/index.html` 内 `prefers-color-scheme` 出现次数 | **0** |
| `local-admin/index.html` 内 `color-scheme` 出现次数 | **0** |

**结论：管理端本就无主题差异，不是"同一张图存了两次"。** 该页面是固定亮色配色（写死的
`#f5f3eb/#193a30` 等取值），没有任何 `prefers-color-scheme`/`color-scheme` 分支，浏览器
`colorScheme: dark` 的 context 渲染不出任何像素差异 → 两张 PNG 字节相同是**预期结果**。
暗色适配正是派发单第 4 项"设计令牌统一（local-admin 与 local-preview 一致）"的范围（等阶段 10
发布报告核验后再做）；在那一项落地之前，管理端截图**只出 light 版**（dark 版与 light 版恒等价）。

## 二、管理员页"匿名质量遥测"只读区（PM 派发第 2 项，mock 验证完成 / 真机被 P0 阻塞）

**对接契约**：`GET /zhku/local-admin/telemetry/aggregates?dimension=&from=&to=`——
以 PM 8136 真机逐项验证的契约为准，并与主线 `TelemetryAdminController` +
`TelemetryAggregateDimension` + `PrivacyBoundary.telemetryAggregateExport` 源码双向核对：
五个受限维度（`route`/`failureCategory`/`handoffRequired`/`latencyBucket`/`eventDate`，
`dimension=bogus` → 400）、缺省窗口近 30 天含首尾（`from>to` → 400）、桶结构
`{ [维度名]: 取值, count, ratio }`、比例 4 位小数、按 count 降序、无数据 `[]`。

**实现要点（local-admin/index.html 新增"7. 匿名质量遥测（只读）"区）**：
- 维度下拉 + 起止日期（缺省显式填近 30 天，与服务端缺省一致，管理员始终看得到当前窗口）；
- 表头/取值列按维度切换（是否转人工维度的布尔值译成"是/否"）；
- **比例展示层用 `toFixed(4)` 补齐尾零**：服务端 BigDecimal `1.0000` 经 JSON 数字解析会丢成 `1`，
  展示层只补格式、不重算、不改序；
- **降级路径全部中性化**：404（端点未上线）→ "观测面尚未启用…"；其他非 2xx → "暂不可用，请稍后重试"；
  网络异常 → "请确认管理端服务已启动"；一律不写全局错误横幅、不白屏；
- `from>to` 由**客户端先拦**（可预防的 400 不当成服务故障展示）；
- 只展示桶/计数/比例，无明细、无自由文本、无身份字段（接口本身也不下发）。

**验证（mock 逐字复刻上述边界 + 系统 Edge 真跑页面，2026-09-23）**：

| 场景 | 断言结果 |
| --- | --- |
| 默认窗口有数据（PM 实测的 2 桶形态） | 表头"路由结论"；`HIGH_RISK_RULE 4 / 0.6667`、`PM_TEMP_ORDER 2 / 0.3333`（4 位小数保留）；汇总"共 2 个取值、6 条事件" |
| 切维度 `handoffRequired` | 表头"是否转人工"；布尔桶渲染为 `否 5 / 0.8333`、`是 1 / 0.1667` |
| 空窗口（`[]`） | 表隐藏，空态"所选窗口内暂无遥测数据。"，汇总"暂无数据" |
| 端点未上线（404） | **优雅降级**：空态"观测面尚未启用：本机管理端还没有遥测聚合接口。"、汇总"未启用"，无错误横幅 |
| `from>to` | 客户端拦截："起始日期不能晚于结束日期。"，不发请求、无错误横幅 |

全部场景 `pageerror` 为 0、外部请求为 0、无横向滚动。截图：
`local-admin.visual-check.1440x900.stage9-telemetry.{data,handoff,empty,unavailable,inverted-window}.png`。

**⚠️ 阻塞与待办**：真机 8124 目前因管理端启动 P0（`TelemetryAdminController` 双构造器缺
`@Autowired`，线 B 修）**起不来**，以上为 mock 取证；**线 B 修复入库后需真机复验一次并补
`local-admin.real-8124.*` 截图**，在那之前不得宣称"已对真实遥测接口验证过"。
