# 公选课重修问法：行为判断与复验证据（2026-09-27）

## 修改前的业务判断

既有课程类型解析把“公选课”识别为公共选修课；既有验收证据为《本科生学生手册（2025版）》PDF 第 77 页、第 18 条：“公共选修课不办理缓考，成绩不合格者不安排重修。”因此，“我公选课不及格了要重修怎么办”已经给出课程类别和重修情境：有合格的已发布证据时，应走既有重修链路，按既有回答卡给出“不安排重修”的规则级结论，无须再追问课程类型。若证据不存在或不符合资格，仍须安全拒答。

“选修课不及格能否重修”没有区分公共与专业选修课，应继续追问。“公选课怎么退课”没有重修意图，不得借类别词误入重修链路。根因是路由器和重修服务各自要求问题字面包含“选修”，而“公选课”虽已能解析类别，却不满足这两个重复的意图门槛。修复应共用一处意图口径，并保留失败情境与“重修”的共同约束，不调整证据资格或学生可见文案。

现行 `five-level-routing-v1` 的 `retake-after-failure` 预期 `AWAITING_CLARIFICATION` 与上述产品契约不符。本轮保留 v1 及 2026-09-26、09-27 历史报告原样；未来 v2 应把该题预期路由修为 `HIGH_RISK_RULE`，将条级引用预期设为 `PDF 第 77 页，第 18 条`，转人工与拒答预期仍为 `false`，并在版本升级时说明原因，而不是用修改 v1 预期掩盖产品漏识别。

## 验证记录

本轮仅验证 `retake-after-failure` 的产品问法，不重跑整个 v1 评测集、不生成或覆盖 2026-09-26/27 的历史报告。数据集仍是 `five-level-routing / v1`，完整语料指纹为 `[EVAL-CORPUS] 学生手册2025版(PDF条级定位) + 当期选课通知2026-2027-1 @ 共享演示库`。

- 修改前先运行两处聚焦测试：15 例中新增的 3 个行为断言按预期失败，实际均为 `OUT_OF_SCOPE`（明确公选课却未进入重修服务、无证据时也未进入安全拒答分支）。
- 修改后单元与真库聚焦回归：9 个相关测试类合计 44 例，0 失败、0 错误、0 跳过。涵盖完整称谓、简称、类别不明仍澄清、退课不误命中、无证据安全拒答、路由、相邻学分/选课调整/通知规则、控制器和 JDBC 检索。

这道题按当前产品契约应为 `HIGH_RISK_RULE`；v1 仍会因旧预期 `AWAITING_CLARIFICATION` 与实际不一致而报错。未来 v2 应把该题改为规则级预期并要求上述条级引用；这属于新版本契约修订，不能追改 v1 历史结果。另两处已知不一致（`credit-limit-per-term` 的预期口径、`notice-window` 的通知服务装配）不在本轮处理范围，仍待独立修复与完整评测复验。
