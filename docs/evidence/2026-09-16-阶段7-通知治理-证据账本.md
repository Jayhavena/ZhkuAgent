# 阶段 7：当期选课通知治理证据账本

> 状态：**进行中**。本记录只描述 2026-09-16 已实现且经自动化验证的部分；本机管理员录入与发布入口已具备，但尚未用一份真实当期通知完成双版本人工验收，不能将阶段 7 标为已验收。

## 技术点：通知时态、替代与可追溯回答

| 字段 | 记录 |
| --- | --- |
| 当前状态 | 已实现核心领域、PostgreSQL 替代事务、本机预览条件接入及本机管理员录入/审核/发布入口；阶段整体仍进行中 |
| 解决的问题 | 避免把旧学期、已替代、未发布、无权利或已过期通知作为当期选课依据 |
| 个人负责范围 | 通知领域模型、Flyway 迁移、JDBC 仓储、时态查询、会话路由、本机管理员发布入口、页面与自动化测试 |
| 核心设计与取舍 | `Clock` 判定 `now >= validTo` 为失效；同一“学期 + 通知类型”仅一个 `PUBLISHED` 版本；发布时事务替代旧版；学生回答引用来源 ID、标题、版本和 PDF 快照哈希。来源可为官网公开通知或已审核校内正式材料，后者不伪造网址 |
| 为什么不采用其他方案 | 不以“最新标题/发布日期”代替替代关系；不在回答生成后才检查时态；不自动抓取官网或接入模型 |
| 关键业务/安全边界 | 动态事实必须有确认的开始/结束时间和 HTTPS 官方入口；无有效通知返回 `EVIDENCE_UNAVAILABLE`，不输出日期、资格或办理承诺；旧快照保留审计但不再被当前查询命中 |

## 代码与迁移位置

- `knowledge/src/main/java/com/zhku/knowledge/notice/`：`AcademicTerm`、通知生命周期、快照、事实、当前查询、JDBC 发布替代与选课通知服务。
- `knowledge/src/main/java/com/zhku/knowledge/conversation/publicelective/PublicElectiveConversationRouter.java`：待澄清 → 动态选课通知 → 静态规则的有限路由。
- `knowledge/src/main/java/com/zhku/knowledge/web/ZhkuLocalPreviewConfiguration.java`：只有显式配置当前学期和官方查询入口时启用通知服务。
- `knowledge/src/main/java/com/zhku/knowledge/governance/` 与 `.../governance/web/`：审核 PDF 暂存区增加 `OFFICIAL_NOTICE` 资料族；管理员只能通过专用接口补齐学期、有效期、官方链接与确认后的办理事实后发布。
- `knowledge/src/main/java/com/zhku/knowledge/notice/NoticeGovernancePublisher.java`：将来源发布、旧来源归档、旧通知替代、新通知与事实写入放在同一 PostgreSQL 事务。
- `knowledge/src/main/resources/zhku/local-admin/index.html`：本机页面对“官方选课通知”展示时态事实表单；不依赖 `innerHTML` 渲染输入内容。
- `knowledge/src/main/resources/db/migration/V6__add_official_notice_lifecycle.sql`：通知、事实、当前范围唯一索引。
- `knowledge/src/main/resources/db/migration/V7__allow_superseded_notice_audit_visibility.sql`：保留被替代通知的审计可见事实，学生端仍由生命周期过滤。
- `knowledge/src/main/resources/db/migration/V8__support_reviewed_internal_official_notice_material.sql`：增加校内正式材料来源路径、签发单位、接收渠道与材料标识；官网链接不再是唯一官方性证明。

## 失败案例与修复记录

首次替代事务测试发现：旧通知改为 `SUPERSEDED` 时，V6 的“学生可见仅限 PUBLISHED”约束会破坏审计历史。根因是把“曾经允许学生可见”与“当前可被学生检索”混为同一字段。通过追加 V7 迁移保留前者，并由 `lifecycle_status = PUBLISHED` 查询条件负责后者；未改写已执行的 V6。

## 已知限制与下一步

1. 本机管理员入口当前只接受可读取的官方 PDF 快照；支持“官网公开通知”及“已审核校内正式材料”两类来源，尚未支持 HTML 网页快照、自动抓取或自动 OCR 纠错。
2. 尚未完成一份真实选课通知与替代通知的人工审核、发布、过期验收。
3. 当前学期和官方查询入口仍需本机显式配置；未配置时通知服务不启用，系统不会猜测当期。
4. 尚未接入 ChatModel、embedding、向量索引、RAG、自动抓取或校务系统。
