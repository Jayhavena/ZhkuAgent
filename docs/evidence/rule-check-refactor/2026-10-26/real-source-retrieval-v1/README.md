# 真实校园规则检索评测用例 v1

状态：**已冻结为开发基线（FROZEN_FOR_DEVELOPMENT_BASELINE_ONLY）**。这不是正式质量报告集、盲测集或学生发布批准。

## 1. 本批用途

本批只回答一个问题：当检索目标固定为一份可追溯的真实校园规则文本时，检索器能否找回回答所需的正确条款。

- 5 条核心用例，来源于既有开发参考 Q05、Q07、Q11、Q17、Q19。
- 预期证据定位到具体条款及 PDF 物理页、印刷页；Q05 是双条款用例，必须同时召回第 4 条和第 18 条。
- 主要看 Recall@K、MRR，并逐题检查“必要证据集合是否完整”。MRR 不能替代完整证据检查。
- 这些问题由项目开发者编写并自核，不是从真实学生日志抽样；已被开发者看过，不是盲测或 holdout。
- 本批冻结的是**指定版本文本的检索金标准**，不是“当前学年仍有效”的结论。

| 用例 | 来源参考 | 必要证据 | 检索关注点 |

## 4. 评分与使用边界

1. 将实际检索候选映射到本文件中的条款定位符；在运行前先确认真实资料确实已被加载到被测检索库，并核实其来源 ID、版本、可见性和发布状态。
2. 对每题的必要条款集合计算 Recall@K；对排名计算 MRR；另记录每题完整证据集合是否齐全。Q05 漏掉任意一条都不能算证据充分。
3. 本批的“历史人工确认”是项目开发者自核（AI 辅助草稿），没有独立第二审核者；rubric 尚未校准。若出现争议，应标记 UNJUDGEABLE 并人工复核，不得自动记通过。
4. 不得将此前使用合成语料的 `RetrievalAcceptanceEvalTest` 的 100% Recall@3 / MRR 复制到本批报告。该测试通过不等于本批真实资料已经运行或通过。
5. 本批尚未接入运行时 sourceId/chunkId，也未在真实资料索引上执行。因此当前没有真实语料检索分数；本次交付是冻结金标准与来源指纹。
6. 当前学期选课截止时间不纳入这 5 条核心指标：2025 手册只指向每学期的《课程选课工作通知》，不能单独提供当期截止日期。须先核验对应学期的正式通知，再另行建立版本化用例。
