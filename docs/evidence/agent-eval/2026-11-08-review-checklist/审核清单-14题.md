## 怎么用

每题按四步核对，再给结论：

1. **问题与预期是否匹配**：这道问法是否真的需要这条规则/事实来回答。
2. **事实与引用是否成立**：`expectedClaim` 是否被 B03 原文逐字支持，locator/页码是否正确。
3. **回答应包含 / 不得声称是否够用**：是否覆盖该题的主要失败模式（扩大结论、编造当期信息、越权等）。
4. **适用条件与缺口是否说清**：该题若考边界，是否明确“仅凭这条不能推出什么”。

结论三选一：通过 / 需修改 / 暂无法判断；需修改时请写具体改哪一条。
