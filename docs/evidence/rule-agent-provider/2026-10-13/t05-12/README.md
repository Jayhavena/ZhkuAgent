## 具体决定

1. 可信事实、对象/时间/条件及权限由程序继续检查；相关性用单独上下文核验原问题与实际已读事实，不采纳提议者自报覆盖。
2. 以事实能力和原子需求对应做确定性检查，比较两侧分别计算；多规则可联合覆盖；无关事实不能靠集合并集被放行。
3. 完整性由宿主在子问题层面聚合；C04漏一侧属于PARTIAL且处理未完成，不伪装成资料缺失。
4. 核验使用现有传输/usage审计与资源所有权，决策3次＋核验1次，同run最多4次；不足或失败停止，不另建隐藏额度。
5. FINISH与ASK都需核验。ASK支持事实允许缺少所追问条件；条件存在、必要性和用户尚未提供由宿主验证。原schemaVersion3快照结构保留，两个新增处理原因需前后端同步。
