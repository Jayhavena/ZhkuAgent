## 二、已覆盖的反例（本地，拒绝且不执行/不发布）

- 协议/结构：坏 JSON、`{}`、`null`、重复键、数组包装、未声明字段、非法枚举、未知动作、`finish_reason=length`、超长响应（>70 KB）。
- 句柄/集合：空句柄、4 个唯一编号、非数组、重复编号、过期集合（`expired-set`）、非 UUID 句柄、越界数量、非当前候选编号。
- 传输/供应商：401、429、503、连接被拒、接收后静默、响应体超时、响应头超时、取消与迟到响应。
- 预算/额度：额度用尽不发请求、审计失败阻止外发、超时消耗额度不退还、无自动重试。
- 核验：错指纹、未声明字段、非法枚举、坏 JSON、重复键、核验超时、共享额度耗尽停止本地。
- 发布门禁：缺同 run 核验不发布；`independentlyAnswerable=false` 或 `when` 不匹配的事实不发布。
