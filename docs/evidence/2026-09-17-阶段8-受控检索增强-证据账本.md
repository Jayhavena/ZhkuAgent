## 评测基线（Recall@K / MRR / 引用准确率）

**首次基线已产出（2026-09-17）**，报告行原文：

```
dataset=retrieval-golden-v1, K=3, N=4, Recall@K=1.0000, MRR=1.0000, 引用准确率=0.8750, 词法路=可用, 向量路=不可用
```

| 项 | 值 |
| --- | --- |
| 评测集版本 | `retrieval-golden-v1`（`RetrievalGoldenSet.VERSION`；冻结，改动须换版本号） |
| 分母 N | 4 个问题（每问声明相关片段集合作为分母） |
| K | 3 |
| Recall@3 | 1.0000 |
| MRR | 1.0000 |
| 引用准确率 | 0.8750（引用取每问前 3 条候选；均值） |
| 路可用性 | 词法路**可用**、向量路**不可用**（降级运行） |
| 运行装置 | `RetrievalAcceptanceEvalTest`（真实 PostgreSQL + Flyway + 真实索引/召回 SQL） |
| 复现命令 | `$env:ZHKU_DB_PASSWORD=...; .\mvnw.cmd -pl knowledge test -Dtest=RetrievalAcceptanceEvalTest` |

**这些数字能说明什么、不能说明什么（必须同时引用）**：

- **能说明**：受控词法路 + 单路降级 + 资格过滤 + 引用组装这条链路，在本机语料上对 4 个同形问法全部找回了相关条款并排在首位；内部资料诱饵在任何一题都没有被召回（资格过滤在召回侧生效）；引用准确率 0.875 的缺口来自"每题引用了前 3 条候选、其中含 1 条同源无关条款"，属召回宽度而非越界引用。
- **不能说明**：① 这不是语义检索效果——**向量路本轮不可用**（本机未配置真实 embedding profile，报告中如实标记），指标只反映"词法路 + 降级融合"；② 词法路是**受控词面匹配**（标点切分 + 长度≥2 词面包含），**不是 BM25、也不是分词检索**；评测问法刻意与条款同形，**真实学生口语问法下的召回大概率更低**；③ N=4 样本极小，不构成生产质量结论；④ 不得据此宣称"性能提升/已上线"。
- **下一步（真实基线）**：接入真实 embedding profile 后重跑同一评测集，报告 `向量路=可用` 的双路版本，并与本基线对比（同一 dataset 版本才有可比性）。

## 失败案例（本阶段已拦截场景）

- 模型引用伪造 citationId → 整答降级（GroundedAnswerComposerTest / RetrievalAugmentedAnswerServiceTest）
- 证据文本含"忽略之前的指令"注入 → 该证据失去支持力，结论降级
- 回答含"登记成功/可以免修"等办理结果断言而证据无同文依据 → 降级
- 模型超时 / 限流 / 5xx / 输出非约定结构 → 降级拒答 + 转人工
- 未发布 / 内部 / 权利未确认 / 维度不符的资料 → 索引与召回两侧均被拒
