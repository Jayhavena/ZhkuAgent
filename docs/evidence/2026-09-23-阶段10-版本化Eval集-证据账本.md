## 隔离与指纹（本批的关键约束）

- **不依赖共享演示库**：数据集是**预期快照**（问题 → 预期结论），加载与校验**纯文件操作、零 DB 访问**——批3 的执行器如果要连真库跑，夹具隔离沿用既有约定（专用标识 + 每例自清）。
- **语料指纹**：`[EVAL-CORPUS] 学生手册2025版(PDF条级定位) + 当期选课通知2026-2027-1 @ 共享演示库`。数据集与 manifest 携带**同一条**指纹，加载器校验两者一致——批3 的基线数字必须连同它一起报告。
- **故意不做字节级 checksum**：git 会规范化行尾（LF/CRLF），字节哈希会因 checkout 环境不同而漂移；改用"版本号 + 用例数 + 指纹 + 清单交叉核对"作为完整性判据（任何实质改动都会导致核对失败或需要升版本号）。
