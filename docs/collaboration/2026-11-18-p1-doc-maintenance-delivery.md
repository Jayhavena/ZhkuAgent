## 4. C4 CI 接入：BLOCKED 的原因与下一版实施条件

**本轮不接入 CI，也不在本地工作流文件上做任何修改。** 原因：

1. 本地 `.github/workflows/agent-eval-chain.yml` 是 2026-11-08 旧版（仅 replay job）；M4 门禁版（trial-contracts + replay，约 +46 行）在 `origin/main @ 5f4391ee`（PR #7）。在旧版上加链接检查 job 会在两线收敛时制造冲突。
2. 直接 `pwsh scripts/validate-doc-links.ps1 -ExcludeEvidence` 并要求零错误**不可行**：排除 Evidence 后仍有 301+19 个历史失效。历史遗留不能成为新 PR 的阻断门禁。

**下一版链接检查门禁的实施条件**（在 M4 基线收敛后，于其 workflow 增加最小步骤）：

- 以本轮基线（301+19）为**历史豁免清单**，不在清单内的失效才判失败；
- **PR 新增的失效链接**是阻断项（对比 PR diff 中新增/修改文档的链接检查结果）；
- 对 **PR 实际修改过的文档**做重点检查（未改动文档不在门禁范围）；
- `docs/evidence/` 源文件不进门禁，历史证据永不被自动改写；
- 门禁摘要只记录文件与计数，不复制证据正文。
