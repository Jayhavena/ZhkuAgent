# 阶段 10：评测、可观测性、隐私与发布门禁实施计划

> 状态：待执行；依赖阶段 7—9 的真实链路。  
> 目标：让系统质量、失败定位、隐私边界和发布条件可以复核，而不是凭演示观感判断。

## 目标与非目标

建设版本化离线 Eval、匿名聚合观测、密钥/留存约束和本地发布质量门禁。该阶段不声称生产 SLO、真实学生效果或高并发能力；没有经授权的真实流量和持续数据，指标只能称为本地受控运行结果。

   > 号段说明（2026-09-17 更正）：原写 `V9` 已被线 A 冻结号段占用（`V9`–`V11`）。**本阶段号段待分配**：需在阶段 9 交付后由线 A 在 `SYNC-STATUS.md` 第五节追认登记（预期自 `V16` 起），登记完成前不得创建迁移文件。
2. [ ] 在 `knowledge/src/test/resources/eval/` 维护版本化 YAML/JSONL 评测集。每题包含：输入、所需前置事实、预期路由、允许/必须引用、禁止推导、是否应拒答/转人工；另维护资料、索引、Prompt、模型 profile 的 manifest。
3. [ ] 实现离线 `EvaluationRunner` 与机器可读报告：检索 `Recall@K`、MRR、nDCG；引用准确率、拒答准确率、关键题逐题结果；运行 p50/p95、错误率、降级数、估算 token 成本。报告必写数据集版本、分母、时间窗、环境、profile 和失败题目。
4. [ ] 定义发布门禁：时态、权限、替代、引用、拒答、提示注入、隐私和密钥扫描为关键用例，必须 100% 通过；其余指标先记录趋势和基线，不设虚构阈值。门禁失败阻止生成“可演示发布”报告。
5. [ ] 为路由、检索、模型调用建立无文本结构化日志/指标：按层定位“未召回 → 候选/融合错误 → 证据正确但表达错误”。日志不可含 Prompt、文档全文、用户输入、模型完整输出、API Key。
6. [ ] 建立密钥、隐私和保留检查：环境变量注入、配置脱敏、90 天匿名明细清理/聚合、导出字段白名单。管理员页面只展示 provider/model/profile/status，不展示 key。
7. [ ] 生成本阶段证据账本和一份本机发布报告；对每个“已实现”指标记录基线而不是宣称提升。

## 先写的测试

- `EvaluationDatasetSchemaTest`：每题必填预期路由、引用/拒答断言和版本；禁止把未标注题计入分母。
- `EvaluationRunnerTest`：指标分母、跳过/失败分类、报告可复现、关键题失败导致门禁失败。
- `CriticalQualityGateTest`：过期通知、权限绕过、替代旧版本、伪造引用、越界推导、注入文本、模型超时均逐题阻断。
- `AnonymousTelemetryTest`：结构化日志和数据库没有原问题、原回答、姓名、学号、联系方式、密钥；配置回显遮蔽。
- `RetentionPolicyTest`：`now >= expiresAt` 清理 90 天明细，聚合数据符合白名单。
- `GracefulDegradationTest`：embedding/ChatModel 不可用、限流、超时、索引 profile 不匹配时，返回安全拒答/人工渠道且记录枚举错误。

## 验收与退出条件

运行带版本的最小 Eval 集并存档报告；关键题 100% 通过；无文本观测、密钥遮蔽、90 天清理和降级测试均通过；人工核验一份发布报告。完成后可诚实表述“在本地受控评测集上完成受控检索、引用、拒答与隐私质量门禁验证”，不可越级称生产上线。

## 不得提前做

- 不收集真实学生会话做评测语料；
- 不用平均分掩盖关键安全题失败；
- 不记录或导出密钥、Prompt、完整回答与可识别信息；
- 不把本地一次运行的延迟或成本写成生产 SLA/节省比例。
