# 阶段 6：公共选修课单学期学分上限设计

## 目标与边界

阶段 6 的第一个垂直切片只回答“单学期公共选修课学分上限”。在既有阶段 4 重修链路和阶段 5
本机会话闭环上，新增一条可追溯、可失效的静态制度规则。

学生可见的确定性结论仅为：**每学期公共选修课最高不得超过 4 学分。**

本切片不计算个人剩余可选学分，不确认具体课程是否开设、能否选上或是否存在当期例外；网络公共选修课
比例、选课退改选、缺课处理、相近课程和缓考边界均不在本切片内。

## 架构

```text
浏览器消息
  ↓
PublicElectiveConversationRouter
  ├─ 会话仍有重修待澄清 → ElectiveRetakeConversationService
  ├─ 命中重修问题       → ElectiveRetakeConversationService
  ├─ 命中学分上限问题   → PublicElectiveCreditLimitService
  └─ 其他问题           → OUT_OF_SCOPE
                              ↓
CreditLimitEvidenceFinder → PostgreSQL 已发布专用证据
                              ↓
阶段 5 ConversationAnswer → 结论 / 依据 / 来源 / 版本 / 条款 / 范围
```

`PublicElectiveConversationRouter` 是唯一的规则分发位置。它先检查是否存在
`ELECTIVE_RETAKE_AFTER_FAILURE` 待澄清，防止用户的“公选课”回复被错误解释为新的学分问题。
阶段 5 的 `LocalPreviewConversationFacade` 和 HTTP 路由保持不变，只把现有单一重修服务替换为该路由。

## 规则识别与回答

### 命中规则

输入必须同时包含：

- `公共选修课`、`公选课` 或 `公共选修课程`；以及
- `学分`；以及
- `每学期`、`一学期`、`最多`、`上限`之一。

仅包含“网络公共选修课”“退选”“缺课”“缓考”“课程相近”等词的输入不命中本规则。

### 回答与边界

| 字段 | 固定要求 |
| --- | --- |
| 结论 | 每学期公共选修课最高不得超过 4 学分。 |
| 依据 | 仅解释该单学期上限，不推导个人可选余额或资格。 |
| 条款定位 | `PDF 第 76—77 页，第 8、10 条` |
| 适用范围 | 办理公共选修课程选课的本科生；个人培养方案与当期通知仍需核对。 |
| 缺少证据 | 返回 `EVIDENCE_UNAVAILABLE`，不输出“4 学分”结论。 |

当用户问“我已经选了 3 学分，还能不能再选 2 学分”时，系统可以说明上限规则，但必须提示它无法基于
口述确认当前已选课程、培养方案要求或当期选课限制，不能承诺个人资格。

## 证据与版本治理

新建独立资料范围 `STUDENT_HANDBOOK/PUBLIC_ELECTIVE_CREDIT_LIMIT`，只存放该规则的审核证据。
证据必须是 PostgreSQL 中已发布、学生可见且当前有效的记录，并保留来源 ID、标题、版本、条款定位、
适用范围与原文校验条件。

独立范围避免更新学分上限时归档或替换下列现有资料：

- `STUDENT_HANDBOOK/ELECTIVE_RETAKE` 重修证据；
- 其他公共选修课程资料；
- 将来依赖当期通知的动态规则资料。

证据替换后，旧版本不再用于学生可见回答；查询不到有效证据时必须安全降级。

## 测试与验收

| 层级 | 最少场景 |
| --- | --- |
| 规则服务 | 标准问法、同义问法、个人资格问法、网络比例反例、无关问题、证据缺失 |
| 路由 | 重修待澄清优先、重修问题路由、学分问题路由、未知问题拒答 |
| PostgreSQL | 仅查询已发布且有效的专用范围；替换版本后旧证据不可见 |
| HTTP | 回答卡包含 7 个来源字段；未知会话与取消行为不回归 |
| 页面 | 使用既有页面显示回答卡；不新增 `innerHTML` 或浏览器直连数据库 |

验收要求：新增测试和现有阶段 1—5 测试均通过；本机页面手工验证标准问法、个人资格问法、重修澄清
优先和证据失效后的降级行为。

## 明确非目标

- 不新增前端框架、RAG、Agent 编排框架或数据库会话持久化；
- 不新增 HTTP 路由或改变阶段 5 的 sessionStorage 协议；
- 不回答网络公共选修课比例、当前选退课时间、具体课程开设或个人毕业学分余额；
- 不把手册静态规则伪装成当前有效选课通知。
