## 复现与运行

在仓库根目录、普通Windows终端运行环境检查：

```powershell
.\knowledge\scripts\start-controlled-manual-demo.cmd -CheckEnvironment
```

该检查不连接数据库、不调用模型、不修改全局PATH或系统编码。实际数据库验收入口每次重新检查本机配置的凭证，仅创建随机容器内的无卷专用临时库，禁止原演示库54329。

复跑合成资料实际HTTP验收，选择一个尚未使用的批次名：

```powershell
.\knowledge\scripts\verify-rule-check-refactor.cmd -Mode Database -Port 55470 -Phase rc1-http-replay-01 -Tests RuleCheckBrowserHttpTest,RuleCheckLegacyBrowserHttpTest
```

正常批次没有浏览器等待，预期3项测试全部通过，结果中 `sourceDrift=0`、`resourcesVerified=true`，无跳过。测试模型仅在test classpath，不调用真实供应商。

完整旧v1人工演示入口仍为：

```powershell
.\knowledge\scripts\start-controlled-web-demo.cmd
```

此入口是既有v1演示，会检查所需环境并在专用临时库运行；不能将它称为已批准的真实v2校园规则查证产品。使用前阅读[演示约束](../../manual/controlled-campus-web-demo.md)。v2工程页面的实际浏览器证据来自受控合成测试宿主，真实规则装配与放行仍待B01–B04。

## 冻结放行标准

1. 已有v2与普通终端证据可核验；与当前代码有关的回归无失败。
2. 旧v1实际浏览器提交得到完成结果，刷新显示已完成记录且不误称仍在受理；退出并换账号清除旧内容，后端继续限制本人记录。
3. 本次自有临时数据库/Java/Nginx正常退出；保留用户浏览器与客户端。
4. 固定Git提交、候选标签及对应材料清单；不混入凭证或个人材料，不修改历史失败证据。

若第2项仍被工具连接阻断，只能称“候选快照已固定、完整A10未放行”。下一次补验收应针对该候选的源码指纹；如改代码，重跑受影响检查并创建下一候选版，不移动既有标签掩盖差异。

## 回退与后续边界

候选标签只在本机创建，不推送、不部署、不合并其他分支。查看旧版应另建隔离目录；不能在当前脏工作区使用reset/clean覆盖剩余本地材料。源代码回退不代表数据库可降级：不删除V21/V22、身份关联或审计记录，真实入口继续关闭。

真实资料绑定/语义审核/展示资格、冻结16题评估、真实模型语义效果和5–8位学生对照试用属于下一阶段。已知自由RAG数值误读风险、Cookie网络交付窗口、发布非原子性和未验证墙钟TTL继续保留，不能由合成工程验收推断为已解决。

## 本轮解决的问题与裁决

- 解决版本标识和制品路径不同步：统一版本并实际打包，保留历史回退引用。
- 解决验收结论不可对应代码：核对既有哈希、生成候选源码/Git材料清单，记录每项未通过的条件。
- 移除agent配置中注释态的口令示例；其他命中经上下文核对为测试数值/虚构电话/引用ID，原件不改写。扫描只记录路径、类型与裁决，不输出凭证。
- 裁决：浏览器策略限制及无可接管标签页不通过其他表面绕过；代价是旧v1页面门禁暂时OPEN。
- 裁决：固定候选快照与完整验收放行分开；代价是此标签不能宣传为面向学生的正式发布。
- 裁决：保留个人材料、历次非本轮证据及临时协作产物在本机；本次材料清单明确排除，不能声称整个工作区已干净。

本轮最终汇总：[verification.json](verification.json)。临时服务已在时限内显式STOP，旧v1页面未操作；网页/数据库均已停止，客户端和用户标签页保留。候选标签计划仅指向本次本地提交，实际Git标识以 `git rev-parse v0.1.0-rc.1^{commit}` 为准。
