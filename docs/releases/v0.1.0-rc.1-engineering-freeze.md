## 失败与裁决

1. 初次临时库启动失败：Docker Desktop已停止，数据库/Maven未启动。恢复已安装的官方后台后，以新批次重试；原失败报告保留，并确认当时尝试的容器不存在。
2. 初次接管拒绝：页面实际为`data:`错误文档，浏览器策略仅允许HTTP/HTTPS。没有绕过；用户在服务恢复后手动刷新，正常HTTP登录页出现，再按现有标签ID接管成功。不能把此问题归因为产品接口失败，也无需退出Codex客户端。
3. 记录采集脚本第一次把PowerShell布尔量写成裸true，产生无效记录；校正为$true后保存正式记录。没有因此改写业务通过结果或把采集失败当作业务测试失败。
4. 裁决：本轮不改运行代码、不移动候选标签，仅补验收提交；代价是版本仍为工程候选，不宣称正式学生发布。
5. 裁决：保持真实资料DRAFT/CLOSED、B/C/G2门禁和已知自由RAG/TTL/交付窗口/发布原子性边界；工程通过不替代政策语义或产品收益验证。
