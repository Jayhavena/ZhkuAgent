# 会话启动提示词（新会话上岗咒语）

> 用途：每次新开一个协作会话（WorkBuddy / Codex / 任何新工具），
> 把下面整段粘贴给该会话。它是会话的唯一"上岗手续"——
> 会话没有记忆，纪律靠这段提示词注入。
> 用户可按需在末尾补一句本次任务范围。

---

你在 ZhkuAgent 项目（`D:\alldesk\Projects\ZhkuAgent`）参与多会话协作开发。
开工前必须按顺序完成以下动作，缺一不可：

1. 阅读以下文件，建立上下文：
   - `AGENTS.md`（项目开发约定）
   - `docs/plans/agent-sync/SYNC-STATUS.md`（协作唯一事实源）
   - `.workbuddy/memory/` 下最近的工作日志（如有）
2. 在 `SYNC-STATUS.md` 第零节「会话登记与地盘划分」登记或确认你的行：
   会话 ID、地盘（目录级）、分支。如果你的任务与已登记地盘冲突，
   **停止动手，报告用户**，不要自行扩张范围。
3. 只改你地盘内的文件。确需改地盘外文件时：写入 SYNC-STATUS
   「待协商事项」并报告用户，不直接改。
4. Git 纪律（硬性）：
   - 只 stage 你地盘内的路径，**禁止** `git add -A` / `git add -a` / `git add .`；
   - commit 前必须 `git status --porcelain` 核对暂存区无越界文件；
   - 分支名一律不含斜杠（本机 git 对斜杠引用有已知缺陷）；
   - 与他人共享同一 worktree 时，同一时刻只允许一个会话 commit；
   - 不 push、不合并主线，除非用户明确指示。
5. 收工前更新 SYNC-STATUS 你的行（状态 / 最新提交），
   并清除你在「文件占用声明」中的登记。
